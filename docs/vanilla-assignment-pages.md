# Vanilla assignment and submission pages — 3.1.0

Canvas owns assignment instructions, submission details and feedback, and the submit/upload views. `ReserveSite.vanillaPage(location)` recognizes `/courses/<numeric id>/assignments/<numeric id>` and every descendant, including trailing slashes, `submissions`, `submissions/new`, `submissions/<user id>`, and feedback paths. Query parameters (including `module_item_id`) and fragments do not change the decision. It works on Instructure and approved custom school origins. Assignment lists and the syllabus remain enhanced.

The global drawn Canvas menu is the sole automatic visual exception. `canvas-nav.js` starts independently on supported Canvas pages and decorates the existing global `#header`; its stylesheet also reserves space for its drawer, column and top layouts. The pony mounts through the Harness workspace's widgets, rather than every native Canvas page, so it is excluded here.

The opt-in PDF reader adds one dormant delegated click listener on these pages. Only a plain primary click on an identified PDF link or Canvas PDF preview creates its split pane and scoped page margin; closing removes them. No reader nodes, styles, storage reads or file requests exist before that interaction. Its reader document owns its own theme and annotations. Ask AI may then open the local AI pane; only Send shares the chosen text with a provider. See [PDF reader](pdf-reader.md) and the dedicated PDF host/model/reader tests for this opt-in exception.

Verification lives in `tests/vanilla-pages.test.cjs`, `tests/vanilla-appearance.test.cjs`, `tests/vanilla-css.test.cjs`, and the updated content/startup lifecycle cases. It covers protected URL shapes, ordinary dashboard/course/module/page/file routes, whole-manifest loading, direct feature creation, delayed appearance completion, opt-in cleanup, and CSS selector/injection boundaries. Existing native course markup timing is still tested on modules.

No browser was launched, so these are automated route, DOM-fixture, lifecycle and stylesheet checks rather than a live Canvas rendering claim. The documentation and preview pass adds no dependencies or remote code.
