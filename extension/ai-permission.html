Canvas Harness · Optional access

Put context in your provider draft

Allow Canvas Harness to append the material you select to a chat draft on the provider website.

  • You choose when to insert context, review the draft, and send it yourself.
  • Your existing draft is preserved. Nothing is sent automatically.
  • Insertion uses only the chat composer. Canvas Harness does not read your passwords, cookies, or chat history.

The browser permission allows script access to this provider website. Canvas Harness uses it only when you explicitly click Insert draft. You can remove this access here or in extension settings.

Checking access…

After allowing access or signing in, return to Canvas and click Insert draft again. Closing this page does not transfer any context. Text placed in the provider’s draft is subject to that provider’s data practices.
