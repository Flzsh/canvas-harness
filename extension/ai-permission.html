Canvas Harness · Optional access

Let Canvas Harness use provider

Allow Canvas Harness to put Canvas text in a chat on the provider website and read the reply.

  • With Send in Tools → AI, the text goes into the chat box and you send it yourself, unless you turned on Send automatically.
  • Daily AI help, Help with this, Ask your AI and the questions you ask on a Help card start a chat, send their message and read the reply. Nothing is sent on its own unless you chose Every day for Daily AI help.
  • To read a reply, Canvas Harness reads the chat it started, using your signed-in session. On ChatGPT it may list your six newest chats (their names and times) to find that chat, and reads only the one created when it sent. On Claude it looks up your account's organizations to reach that chat.
  • It does not read your passwords or cookies, keeps only the reply to its own message, and does not open your other chats. A draft already in the chat box is never replaced.

The browser permission allows script access to this provider website. Canvas Harness uses it only for the requests above. You can remove this access here or in extension settings.

Checking access…

After allowing access or signing in, return to Canvas and click Send again. Closing this page does not transfer any context. Text placed in the provider’s draft is subject to that provider’s data practices.
